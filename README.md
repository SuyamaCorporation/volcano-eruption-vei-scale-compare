# 火山噴火 VEI スケール 比較ビジュアライザー

VEI 0〜8のスケールを対数グラフで比較する火山噴火可視化ツール。

## 機能
- VEIスケール一覧表（噴出量・噴煙高・頻度・事例）
- 噴出量比較棒グラフ（対数スケール・Canvas描画）
- 噴煙高さ比較棒グラフ（km・Canvas描画）
- 主要噴火事例カード
  - 富士山 宝永噴火 1707 (VEI 5)
  - クラカタウ 1883 (VEI 6)
  - ピナトゥボ 1991 (VEI 6)
  - タンボラ山 1815 (VEI 7)

## VEIとは
Volcanic Explosivity Index（火山爆発指数）。噴出物の量を対数スケールで表す。
VEIが1上がるごとに噴出量が約10倍増加する。
